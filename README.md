# Домашнее задание — потоки и синхронизация

## Цель

Написать TCP-эхо-сервер по модели thread-per-connection, защитить общий счётчик подключений мьютексом и обеспечить корректное завершение без потери дескрипторов.

## Состав проекта

- `server.c` — сервер на C и POSIX Threads.
- `test_clients.py` — проверка трёх одновременных TCP-клиентов.
- `client_output.txt` — фактический вывод тестовых клиентов.
- `server_output.txt` — фактический вывод сервера.
- `Эссе_многопоточность.docx` — эссе на одну страницу.

## Сборка

Требуется Linux с поддержкой POSIX Threads.

```bash
cc -std=c11 -Wall -Wextra -Wpedantic -O2 -pthread server.c -o server
```

## Запуск

В первом терминале:

```bash
./server 9000
```

Во втором терминале:

```bash
python3 test_clients.py 9000
```

По умолчанию обе программы используют порт `9000`. Сервер слушает только `127.0.0.1` для безопасного локального тестирования. Для остановки нажать `Ctrl+C` в окне сервера.

## Принцип работы

Главный поток принимает подключения с помощью `accept()` и запускает отдельный рабочий поток для каждого клиента. Рабочий поток читает данные через `recv()`, полностью возвращает полученные байты через `send()` и закрывает собственный клиентский сокет. Общие переменные `active_clients` и `total_clients` изменяются под защитой `pthread_mutex_t`. Условная переменная позволяет главному потоку дождаться завершения всех клиентов перед выходом. Сигнал `SIGINT` или `SIGTERM` устанавливает флаг остановки; сервер завершает приём новых подключений, дожидается рабочих потоков и освобождает ресурсы.

Для приёма и передачи предусмотрены повторные попытки после `EINTR`, а также обработка таймаутов `EAGAIN` / `EWOULDBLOCK`. Цикл `send()` учитывает частичную отправку. Проверка соединений выполняется одновременно, используя барьер из трёх потоков теста.

## Результаты проверки

Программа собрана с `-Wall -Wextra -Wpedantic`, предупреждений компилятора не получено. Три клиента одновременно отправили по 44 000 байт. Каждый получил в точности отправленные данные.

```text
Клиент 1: получено 44000 байт, эхо совпало
Клиент 2: получено 44000 байт, эхо совпало
Клиент 3: получено 44000 байт, эхо совпало
```

После завершения теста сервер остановлен через `SIGINT`:

```text
Сервер остановлен. Всего подключений: 3; активных клиентов: 0
```

Полные журналы находятся в `client_output.txt` и `server_output.txt`. Наличие нулевого счётчика при остановке подтверждает завершение рабочих потоков в данном запуске; отдельная проверка инструментами поиска утечек не выполнялась.

## Итог

Реализована модель «один поток на подключение», общий счётчик защищён мьютексом, три клиента работают одновременно. Завершение сопровождается ожиданием рабочих потоков и закрытием сокетов.
